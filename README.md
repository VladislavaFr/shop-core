Проект shop-core демонстрирует работу с классами интернет-магазина на Python.  
Он предназначен для изучения основ объектно-ориентированного программирования (ООП) и написания тестов с использованием pytest.

## Классы

### Product
Класс продукта интернет-магазина с основными атрибутами:
- name — название продукта
- description — описание продукта
- price — цена продукта (float)
- quantity — количество продукта на складе (int)

### Category
Класс категории товаров:
- name — название категории
- description — описание категории
- products — список объектов Product
- Класс хранит два атрибута:
  - category_count — количество созданных категорий
  - product_count — количество продуктов во всех категориях

## Основные функции

- Загрузка категорий и продуктов из JSON-файла через функцию load_categories_from_json(file_path)
- Подсчёт категорий и продуктов
- Примеры инициализации объектов в блоке if __name__ == "__main__":  # pragma: no cover

## Технологии

- Python 3.11+
- Pytest для тестирования
- Pytest-cov для проверки покрытия тестами
