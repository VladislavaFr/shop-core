# Shop Core

**Shop Core** — это ядро интернет-магазина (e-commerce), реализованное на Python с использованием объектно-ориентированного программирования (ООП).  

---

## 📦 Функциональность

В проекте реализованы основные сущности интернет-магазина:

### 🧩 Класс `Product`
Описывает товар интернет-магазина.  
Содержит следующие атрибуты:
- `name` — название товара;
- `description` — описание;
- `price` — цена (float);
- `quantity` — количество в наличии (int).

### 🗂️ Класс `Category`
Описывает категорию товаров.  
Содержит:
- `name` — название категории;
- `description` — описание категории;
- `products` — список объектов класса `Product`.

А также имеет **атрибуты класса**:
- `category_count` — общее количество созданных категорий;
- `product_count` — общее количество товаров во всех категориях.

Количество категорий и продуктов рассчитывается автоматически при создании объектов.

### 📁 Функция `load_categories_from_json(file_path)`
Загружает данные о категориях и товарах из JSON-файла и создает соответствующие объекты `Category` и `Product`.

## 🧠 Технологии проекта

- Python 3.13
- Poetry (для управления зависимостями и окружением)
- Pytest — для тестирования
- Pytest-cov — для анализа покрытия кода тестами
- Flake8 — для проверки качества кода

---

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd shop-core
   ```

2. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```

3. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```

4. Запустите тесты и проверьте покрытие:
   ```bash
   pytest --cov=shop_core --cov-report=html
   ```

После выполнения появится папка `htmlcov` с отчетом о покрытии тестами (более 75%).

## ✅ Проверка стиля кода

Для проверки соблюдения PEP8:
```bash
flake8
```

Параметры проверки заданы в файле `.flake8`.

---

## 🧪 Тестирование

Тесты расположены в директории `tests/`.

Проверяется:
- корректность инициализации объектов классов `Product` и `Category`;
- подсчет количества категорий и товаров;
- корректность загрузки данных из JSON-файла.
